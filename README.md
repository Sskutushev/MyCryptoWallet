# 🚀 DexSafe Wallet Pro

## 📄 Концепция и Текущее Состояние

**DexSafe Wallet Pro** — это прототип некастодиального Web3-кошелька, разработанный как Telegram Mini App. Основная идея — создать удобный и безопасный инструмент для управления криптовалютными активами с упором на экологичный блокчейн **X1 EcoChain** и интеллектуальную маршрутизацию транзакций через **UPA Engine**.

На данный момент проект представляет собой **полностью функциональную основу кошелька с реализованным UI и базовой логикой**, готовый к дальнейшему наращиванию сложного функционала.

## 🏗️ Архитектура

Проект построен на принципах **модульности и безопасности**.

1.  **Frontend (React + TypeScript):**
    *   **UI Слой:** Набор переиспользуемых компонентов в `src/components`.
    *   **State Management:** Глобальное состояние управляется через `zustand` (`useWallet`, `useSettingsStore`, `useDeFiStore`, `useUPAStore`).
    *   **Web3 Логика:** Изолирована в хуке `useWallet` и сервисах в `src/lib`.
    *   **Безопасность:** Приватные ключи **не хранятся в открытом виде**. Они шифруются паролем пользователя с помощью `ethers.js` и хранятся в `localStorage`. Расшифровка происходит только в момент разблокировки кошелька, и ключ помещается в переменную, доступную только в рамках текущей сессии.

2.  **Sidecar UPA Engine (Внешний сервис):**
    *   Кошелек взаимодействует с внешним сервисом UPA (Universal Payment Agent) для получения оптимальных маршрутов транзакций. Интеграция реализована через `upaEngine.ts`.

3.  **Блокчейн (X1 EcoChain):**
    *   Взаимодействие с X1 EcoChain происходит через `x1Provider`, который является оберткой над `ethers.JsonRpcProvider`.

## 🚀 Начало Работы

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта, скопировав содержимое из `.env.example`:

```bash
cp .env.example .env
```

Заполните переменные:

-   `VITE_UPA_ENGINE_URL`: URL вашего UPA Engine бэкенда.
-   `VITE_X1_RPC_URL`: URL RPC-ноды для X1 EcoChain.

### 3. Запуск проекта

```bash
npm run dev
```

Проект будет доступен по адресу `http://localhost:3000` (или другому порту, если 3000 занят).
