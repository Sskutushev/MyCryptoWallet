# 🚀 DexSafe Wallet Pro: Детальный Обзор Проекта

## 📄 1. Концепция и Текущее Состояние

**DexSafe Wallet Pro** — это прототип некастодиального Web3-кошелька, разработанный как Telegram Mini App. Основная идея — создать удобный и безопасный инструмент для управления криптовалютными активами с упором на экологичный блокчейн **X1 EcoChain** и интеллектуальную маршрутизацию транзакций через **UPA Engine**.

На данный момент проект представляет собой **функциональную основу кошелька с реализованным UI и базовой логикой**, готовый к дальнейшему наращиванию сложного функционала. В ходе разработки были учтены принципы безопасности, модульности и производительности.

## 🏗️ 3. Архитектура Проекта

Проект построен на принципах **модульности, безопасности и масштабируемости**.

1.  **Frontend (React + TypeScript):**
    *   **UI Слой:** Набор переиспользуемых компонентов, организованных по фичам (`balance`, `defi`, `bonuses`, `common`, `layout`, `upa`).
    *   **State Management:** Глобальное состояние управляется через `zustand` (хуки `useWallet`, `useSettingsStore`, `useDeFiStore`, `useUPAStore`).
    *   **Web3 Логика:** Изолирована в хуке `useWallet` и сервисах в `src/lib/web3`.
    *   **Безопасность:** Приватные ключи **не хранятся в открытом виде**. Они шифруются паролем пользователя с помощью `ethers.js` и хранятся в `localStorage` через `secureStorage.ts`. Расшифровка происходит только в момент разблокировки кошелька, и ключ помещается в переменную, доступную только в рамках текущей сессии.
    *   **Интернационализация:** Поддержка нескольких языков через `i18next`.

2.  **Sidecar UPA Engine (Внешний сервис):**
    *   Кошелек взаимодействует с внешним сервисом UPA (Universal Payment Agent) для получения оптимальных маршрутов транзакций. Интеграция реализована через `upaEngine.ts`.

3.  **Блокчейн (X1 EcoChain):**
    *   Взаимодействие с X1 EcoChain происходит через `x1Provider`, который является оберткой над `ethers.JsonRpcProvider`.
    *   Конфигурация поддерживаемых сетей находится в `chainConfig.ts`.

## 🚀 6. Начало Работы

### 6.1. Установка зависимостей

```bash
npm install
```

### 6.2. Настройка переменных окружения

Создайте файл `.env` в корне проекта, скопировав содержимое из `.env.example`:

```bash
cp .env.example .env
```

Заполните переменные (пример):

-   `VITE_INFURA_KEY=your_infura_key` (для Ethereum RPC)
-   `VITE_UPA_ENGINE_URL=https://upa-engine.dexsafe.io` (URL вашего UPA Engine бэкенда)
-   `VITE_X1_RPC_URL=https://rpc.x1-ecochain.network` (URL RPC-ноды для X1 EcoChain)
-   `VITE_TELEGRAM_BOT_TOKEN=your_bot_token` (токен вашего Telegram-бота)

### 6.3. Запуск проекта

```bash
npm run dev
```

Проект будет доступен по адресу `http://localhost:3000` (или другому порту, если 3000 занят).

## ⚠️ 7. Текущие Ограничения и Известные Проблемы

*   **Тестовое окружение:** Запуск тестов (`npm test`) может быть нестабилен из-за проблем с `jsdom` и `ethers.js` в тестовой среде. Это не влияет на сборку и работу приложения.
*   **UPA Engine:** Интеграция UPA Engine на данный момент только предлагает маршруты. Логика *исполнения* этих сложных маршрутов (свопы, мосты) не реализована.
*   **Mock-данные:** Многие разделы (список токенов, DeFi, геймификация) используют mock-данные и требуют интеграции с реальным бэкендом.

### 🔐 Безопасность

- **Некастодиальность**: Приватные ключи хранятся только у пользователя
- **Шифрование**: AES-256 для хранения в localStorage
- **PBKDF2**: Генерация ключа из пароля пользователя
- **Session-only**: Приватные ключи расшифровываются только в памяти

### 🚧 Текущие ограничения

1. **Тестовое окружение**: Проблемы с запуском тестов из-за jsdom и ethers.js
2. **UPA Engine**: Только предлагает маршруты, не исполняет сложные транзакции
3. **Mock-данные**: Многие разделы используют заглушки
4. **Только X1 EcoChain**: Пока поддержка только одной сети
5. **Нет P2P**: Функционал P2P торговли отсутствует
