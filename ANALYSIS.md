## 🎯 Основная цель проекта

DexSafe Wallet Pro - это некастодиальный Web3-кошелек, разработанный как Telegram Mini App с упором на экологичный блокчейн X1 EcoChain и интеллектуальную маршрутизацию транзакций через UPA Engine.

## 🛠 Технологический стек

### Frontend
- **React 18** - основной фреймворк
- **TypeScript 5** - строгая типизация
- **Vite 5** - сборка и разработка

## 🏗 Архитектура приложения

### Основные компоненты системы

1. **Frontend (React + TypeScript)**:
   - UI Слой: Набор переиспользуемых компонентов, организованных по фичам
   - State Management: Глобальное состояние управляется через Zustand
   - Web3 Логика: Изолирована в хуке useWallet и сервисах в src/lib/api
   - Безопасность: Приватные ключи шифруются паролем и хранятся в localStorage
   - Интернационализация: Поддержка нескольких языков через i18next

2. **Sidecar UPA Engine**:
   - Внешний сервис для получения оптимальных маршрутов транзакций
   - Интеграция через upaEngine.ts

3. **Блокчейн (X1 EcoChain)**:
   - Взаимодействие через x1Provider на основе ethers.JsonRpcProvider
   - Конфигурация сетей в chainConfig.ts

## 🚧 Текущие ограничения

1. **Тестовое окружение**: Проблемы с запуском тестов из-за jsdom и ethers.js
2. **UPA Engine**: Только предлагает маршруты, не исполняет сложные транзакции
3. **Mock-данные**: Многие разделы используют заглушки
4. **Только X1 EcoChain**: Пока поддержка только одной сети
5. **Нет P2P**: Функционал P2P торговли отсутствует
