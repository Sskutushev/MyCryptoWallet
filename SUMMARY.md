## 🎯 Основная цель

DexSafe Wallet Pro - некастодиальный Web3-кошелек, разработанный как Telegram Mini App с упором на экологичный блокчейн X1 EcoChain и интеллектуальную маршрутизацию транзакций через UPA Engine.

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript 5, Vite 5
- **Стилизация:** Tailwind CSS 3.4.0
- **State Management:** Zustand
- **Анимации:** Framer Motion
- **Web3:** Ethers.js 6, Viem/Wagmi
- **Иконки:** Lucide React
- **Интернационализация:** i18next
- **Тестирование:** Vitest + React Testing Library
